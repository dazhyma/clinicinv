# Требования: веб-система учёта инвентаря и расходных материалов клиники

Источник истины — `Clinic_Inventory_System_TZ_RU.md` v1.0.
Документ технологически нейтрален: описывает **что** система делает и какие инварианты держит, без выбора языка, фреймворка, БД и хостинга.

## Легенда

| Метка | Значение |
| --- | --- |
| **MVP** | Обязательно для первой версии (раздел 19 ТЗ) |
| **V2** | Отложено во вторую версию (раздел 20 ТЗ) |
| **OPT** | ТЗ явно называет функцию опциональной; в MVP допустимо не делать |
| **§N** | Ссылка на раздел ТЗ |
| ⚠ | Требование зависит от незакрытого решения — см. `open-questions.md` |

Каждое требование сформулировано так, чтобы его можно было проверить: наблюдаемое действие → наблюдаемый результат.

## Сводка по объёму

**Входит в MVP (§19):** авторизация и две роли; главная страница; создание и редактирование предметов; фотографии; автогенерация и печать штрихкодов; поиск; текущие остатки; поступление; ручная корректировка; инвентаризация; цифровые паки и их штрихкоды; создание операции; сканирование предметов и паков; ручной поиск; изменение количества; Undo; автосохранение; восстановление после refresh; статусы Active/Finished/Voided; фиксация исторической стоимости; возврат остатков при Void; история операций; сводка материалов; базовая защита и резервное копирование.

**Отложено во вторую версию (§20):** FR-43, FR-46, FR-53, FR-63, FR-92, FR-121, FR-127 — offline-first, экспорт CSV/PDF, отчёты по прибыльности, ввод дохода, аналитика и графики, прогноз закупок, уведомления о низком остатке, expiration date, lot number, партионный учёт и FIFO/weighted-average, физические паки, массовая печать разных этикеток, импорт из CSV, интеграция с Symplast.

**Опционально в MVP (ТЗ допускает отсутствие):** FR-22, FR-40, FR-41, FR-126.
